## 🇫🇷 ParisEvents

**ParisEvents** est un projet scolaire front-end ayant pour objectif de créer un site web affichant des événements parisiens à partir d'une API open data gratuite récupérée sur **Paris Data**.

### 🎯 Objectifs du projet

- 🔌 Consommation d'une API open data via [opendata.paris.fr](https://opendata.paris.fr/)
- 📋 Affichage des événements sous forme de **liste**
- 🔍 Système de **filtres** pour affiner les résultats
- 📄 Système de **pagination** pour naviguer entre les données
- 🎨 Mise en valeur des données grâce à un **CSS personnalisé**

### 🛠️ Stack technique

- HTML
- CSS
- JavaScript

### 🌍 Langue

Le site est actuellement disponible **uniquement en français**.

### ⚠️ Version scolaire

> Ce projet a été réalisé dans un cadre scolaire. Il s'agit d'une version figée correspondant au rendu final du projet.

## 🇬🇧 ParisEvents

**ParisEvents** is a front-end school project with the goal of building a website displaying Parisian events using a free open data API from **Paris Data**.

### 🎯 Project objectives

- 🔌 Fetching data from an open data API via [opendata.paris.fr](https://opendata.paris.fr/)
- 📋 Displaying events as a **list**
- 🔍 **Filtering system** to refine results
- 📄 **Pagination system** to browse through the data
- 🎨 Highlighting data through **custom CSS styling**

### 🛠️ Tech stack

- HTML
- CSS
- JavaScript

### 🌍 Language

The site is currently available **in French only**.

### ⚠️ School project

> This project was completed as part of a school assignment. It is a frozen version corresponding to the final project submission.
